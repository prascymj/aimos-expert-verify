# AI-MOS Expert Verification

Web page for licensed pharmacists invited to review AI-MOS, a research prototype for screening outpatient
medication orders (School of Applied Digital Technology, Mae Fah Luang University).

- Sign-in with Google; only accounts invited by the research team can use the page.
- The page holds no study content. Synthetic cases and rules are served by the project's API after sign-in,
  and answers are stored under a pseudonymous reviewer code.
- Educational and research prototype only. Not medical advice, and no real patient data is used.
